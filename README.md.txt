# E-Commerce Sales Dashboard

## Project Overview
An interactive dashboard built using Power BI and PostgreSQL to analyze e-commerce sales performance.

## Tools
- Power BI Desktop
- PostgreSQL
- DAX

## Key Metrics
- Total Revenue
- Total Orders
- Total Customers
- Repeat Customers

## Visualizations
- Monthly Revenue Trend
- Orders by Category
- Revenue by Country
- Top 10 Products by Revenue
- Top 10 Customers

## Data Model
Customers, Orders, Order Items, and Products tables connected through relationships.
